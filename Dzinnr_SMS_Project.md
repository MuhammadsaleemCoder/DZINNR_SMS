# Dzinnr School Management System (SMS)

## Project Overview

A simple and real-world MERN Stack project for the Dzinnr Academy
portfolio.

------------------------------------------------------------------------

## Features

### 1. Authentication

-   Admin Login
-   Teacher Login
-   Student Login

------------------------------------------------------------------------

### 2. Dashboard

#### Admin Dashboard

-   Total Students
-   Total Teachers
-   Total Classes
-   Total Fees Collected

------------------------------------------------------------------------

### 3. Student Management

-   Add Student
-   View All Students
-   Update Student
-   Delete Student

**Example:** - Name: Muhammad Saleem - Class: 10th - Roll No: 15 - Phone
Number

------------------------------------------------------------------------

### 4. Teacher Management

-   Add Teacher
-   View Teachers
-   Update Teacher
-   Delete Teacher

**Example:** - Name: Ali Khan - Subject: Computer Science

------------------------------------------------------------------------

### 5. Attendance Management

-   Mark Attendance
-   View Attendance

**Example:** - Muhammad Saleem -- Present - Ahmed Ali -- Absent

------------------------------------------------------------------------

### 6. Fee Management

-   Add Fee
-   View Fee Status
-   Paid / Unpaid Status

**Example:** - Student: Muhammad Saleem - Monthly Fee: 5000 PKR -
Status: Paid

------------------------------------------------------------------------

### 7. Notice Board

-   Add Notice
-   Delete Notice
-   View Notices

**Example Notices:** - Tomorrow is a holiday. - MERN class will start at
10:00 AM.

------------------------------------------------------------------------

### 8. Profile Page

All users can: - View Profile - Update Profile Picture

------------------------------------------------------------------------

## Project Flow

``` text
Login

Dashboard

Students

Fees
Notices
Profile
```
